# Practice Project Ideas

A small finished project teaches more than a large unfinished one.

## Build

Create a personal profile page, a Markdown cheat sheet, a command-line habit tracker, a static event page, or a small accessibility audit.

## Contribute

Improve documentation, add examples, translate a page, write a test, reproduce a bug, or improve a project’s onboarding instructions.

## Share your learning

Add a README with purpose, setup, usage, limitations, and what you learned. That documentation is part of the project.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
