# Useful Tools

Choose tools that reduce friction without hiding the underlying workflow.

## Core tools

Git, a code editor such as VS Code, a terminal, and a web browser are enough for most first contributions.

## Friendly interfaces

GitHub Desktop can make branching and history easier to see. Markdown preview tools help you catch formatting issues.

## Safety

Download software from official sources, keep it updated, and never paste credentials into extensions or unknown scripts.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
