# GitHub Newbie Cheat Sheet

A one-page reminder for the basic workflow.

## Workflow

`Fork → Clone → Branch → Edit → Test → Commit → Push → Pull Request`

## Commands

```bash
git status
git switch -c my-change
git diff
git add .
git commit -m "describe the change"
git push -u origin my-change
```

## Remember

Read the project rules, keep changes focused, never share secrets, and ask clear questions.
