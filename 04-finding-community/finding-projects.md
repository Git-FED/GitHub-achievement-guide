# Finding Beginner-Friendly Projects

The best first project is active, documented, and aligned with something you want to learn.

## Search signals

Try labels such as `good first issue`, `first-timers-only`, `help wanted`, or `documentation`. Search the repository topics and GitHub Explore as well.

## Evaluate fit

Read the README and CONTRIBUTING files. Check recent commits, issue responses, supported versions, license, code of conduct, and whether the issue is still open.

## Start beyond code

Documentation, translations, tests, design feedback, accessibility fixes, examples, and issue triage are valuable contributions.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
