# Pull Request Checklist

Copy this checklist into your notes before opening a pull request.

## Before opening

- [ ] I read the project instructions.
- [ ] My branch contains one focused change.
- [ ] I checked the diff.
- [ ] I ran the relevant tests or checks.
- [ ] I removed secrets and temporary files.

## Description

- [ ] The title is specific.
- [ ] The body explains the problem and solution.
- [ ] Testing is documented.
- [ ] Related issues are linked.
- [ ] Screenshots or accessibility notes are included when useful.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
