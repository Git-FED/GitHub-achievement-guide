# Your First Contribution

This end-to-end example assumes a fork-based contribution to a public repository.

## Prepare

Read the repository rules, choose one issue, and comment only when the project asks contributors to claim work.

## Work locally

```bash
git clone https://github.com/YOUR-USERNAME/PROJECT.git
cd PROJECT
git switch -c docs/clarify-setup
# make one focused edit
git diff
git add .
git commit -m "docs: clarify setup"
git push -u origin docs/clarify-setup
```

## Open the pull request

Use the project template. Explain the problem, the change, testing performed, and any limitations. Link the issue when appropriate.

## After submission

Watch checks, answer questions, revise the branch when requested, and keep the conversation respectful.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
