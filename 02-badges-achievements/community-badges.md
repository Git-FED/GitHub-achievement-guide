# Community and Program Badges

Some badges belong to events, projects, or community tools rather than GitHub itself.

## Examples

Project contributor graphics, All Contributors entries, event participation badges, and program recognition may be awarded by different organizations.

## Verify ownership

Read the official program rules. Check whether a badge is earned automatically, added by a bot, or displayed through a profile tool. Avoid copying brand assets without permission.

## Display responsibly

Link to the source, keep alt text meaningful, and remove badges that no longer represent your current participation.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
