# GitHub Achievements

Achievements are optional profile signals. Treat them as a by-product of useful collaboration, not as a reason to create noise.

## Common achievements

GitHub has used achievements such as Pull Shark, Quickdraw, Pair Extraordinaire, YOLO, Galaxy Brain, and others. Names, criteria, and availability can change, so verify current requirements in GitHub Help and your profile.

## Safe ways to participate

Make a real pull request, collaborate with another contributor, answer a genuine discussion question, or review work when you have enough context. Do not manufacture issues, duplicate changes, or pressure maintainers.

## Practice safely

Use the included sandbox to learn the workflow. A practice contribution should still follow the repository rules and should not create unnecessary work for maintainers.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
