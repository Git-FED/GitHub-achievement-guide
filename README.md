A practical, welcoming path from creating a GitHub account to making a confident first open-source contribution.

## Start here

Begin with [00-start-here/roadmap.md](00-start-here/roadmap.md), then follow the numbered folders in order. You can read one guide at a time or jump directly to the problem you are solving.

## What you can do here

- Set up and secure your profile.
- Learn the Git and GitHub workflow.
- Explore achievements, programs, and community events.
- Find projects that welcome beginners.
- Download printable checklists and templates.
- Practice a real pull request in the [sandbox](sandbox/README.md).

## Roadmap

1. Set up your account.
2. Learn the vocabulary and interface.
3. Find a project and a small task.
4. Make, test, and submit a change.
5. Meet people and keep contributing.
