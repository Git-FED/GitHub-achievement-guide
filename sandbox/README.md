# Practice Sandbox

This folder is a safe place to practice the mechanics of a pull request. It is intentionally simple.

## Practice task

Fix the deliberate typo in [practice-typo.md](practice-typo.md), add your name to [contributors.md](contributors.md), and open a pull request against your fork.

## Rules

Use a real Git workflow, make one focused change, and do not add private information. The exercise is about learning, not earning a badge.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
