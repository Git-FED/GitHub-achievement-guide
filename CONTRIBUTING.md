# Contributing

This guide is built by people who remember what it felt like to be new. Small improvements are valuable.

## Good contributions

Fix a typo, clarify a command, add a reputable learning link, improve accessibility, update a stale date, or add a beginner-safe example.

## Workflow

Open an issue for a large change. Fork the repository, create a focused branch, make the smallest useful edit, check links and formatting, and open a pull request with a clear summary.

## Writing style

Use plain English, define unfamiliar terms, prefer commands that are safe to copy, and avoid promising that a program or badge is guaranteed. Do not include referral links or spam.

## Review standard

Every factual or time-sensitive claim should point readers toward an official source. Reviewers may request changes when a link is stale, a step is unsafe, or the wording is not welcoming.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
