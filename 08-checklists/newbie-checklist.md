# Newbie Checklist

Work through these items at your own pace.

## Account

- [ ] Create and verify an account.
- [ ] Add a bio and avatar if desired.
- [ ] Enable 2FA and store recovery codes safely.
- [ ] Review notifications and authorized apps.

## Learning

- [ ] Read the glossary.
- [ ] Fork and clone a practice repository.
- [ ] Create a branch and commit a change.
- [ ] Open a pull request.

## Community

- [ ] Read a project code of conduct.
- [ ] Ask one clear question.
- [ ] Thank someone who helped you.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
