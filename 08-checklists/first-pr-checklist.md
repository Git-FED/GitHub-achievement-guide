# First Pull Request Checklist

Use this from fork to merge.

## Before coding

- [ ] Read README and CONTRIBUTING.
- [ ] Confirm the issue is available.
- [ ] Fork and clone the project.

## During coding

- [ ] Create a focused branch.
- [ ] Make the smallest useful change.
- [ ] Run checks.
- [ ] Review the diff.

## Before opening

- [ ] Write a descriptive title.
- [ ] Explain testing.
- [ ] Link the issue.
- [ ] Remove secrets and unrelated edits.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
