# Code of Conduct

We want this project to be a respectful learning space for people of every background and experience level.

## Expected behavior

Be kind, patient, constructive, and specific. Welcome questions. Give credit. Assume good intent while addressing impact.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, sexualized conduct, spam, and deliberate disruption are not acceptable.

## Reporting

Report a concern privately to the project maintainers rather than arguing about it in a public thread. A maintainer may remove content or restrict participation when necessary to keep the space safe.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
