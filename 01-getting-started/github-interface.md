# GitHub Interface Tour

The interface becomes less intimidating when each area has a clear job.

## Repository

The Code tab contains files and history. Issues track work. Pull requests review proposed changes. Actions automate checks. Discussions support open-ended conversation.

## Profile

Your profile shows activity, repositories, contributions, and public identity settings. Check visibility before posting anything sensitive.

## Settings

Repository settings control access, branch protections, webhooks, and automation. Account settings control security, notifications, and connected applications.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
