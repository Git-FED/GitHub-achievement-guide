# Account Security

Security protects your work and your identity. Set it up before you become active in many projects.

## Two-factor authentication

Enable 2FA in GitHub settings. Prefer an authenticator app or hardware security key, and save recovery codes somewhere private and offline.

## SSH keys and tokens

Use an SSH key or a short-lived token when a tool requires authentication. Never paste a token into an issue, commit, screenshot, or chat.

## Notifications

Tune notification settings so important review requests are visible without creating unnecessary noise. Unsubscribe from repositories you no longer follow.

## Recovery plan

Keep recovery codes secure, review authorized applications, and know how to revoke a compromised token or key.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
