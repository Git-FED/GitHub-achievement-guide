# Profile Setup

Your profile is a public introduction, not a test. Make it accurate, useful, and comfortable to maintain.

## Profile basics

Choose a clear avatar, write a short bio, add your location or time zone only if you want to, and link to a portfolio or personal site when appropriate.

## Pinned repositories

Pin a small set of projects that show what you are learning or building. Add a useful README to each pinned project.

## Profile README

Create a public repository whose name exactly matches your username. Add a short introduction, current learning goals, selected projects, and contact preferences.

## Keep it current

Review your bio and pinned projects every few months. Remove credentials, private information, and claims you cannot support.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
