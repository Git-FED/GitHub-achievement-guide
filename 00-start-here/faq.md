# Frequently Asked Questions

Short answers to common questions from people who are new to GitHub.

## Do I need to be an expert?

No. You need a small task, willingness to read instructions, and the ability to ask a clear question.

## What is a fork?

A fork is your personal copy of another repository on GitHub. It lets you propose changes without direct write access to the original project.

## What is a pull request?

A pull request asks maintainers to review proposed changes and decide whether to merge them.

## Can I earn badges without spamming?

Yes. Use real collaboration and meaningful changes. Never open low-quality pull requests just to trigger a metric.

## What if my pull request is rejected?

Rejection is feedback about one change, not a judgment of your potential. Ask what would make the contribution useful and try again.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
