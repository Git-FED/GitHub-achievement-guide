# GitHub and Open Source Glossary

Plain-English definitions for common terms.

## Repository

A project space containing files, history, issues, pull requests, and collaboration settings.

## Clone

Download a repository from GitHub to your computer so you can work on it locally.

## Branch

A separate line of work that keeps changes isolated until they are ready to review.

## Commit

A saved snapshot of changes with a message describing what changed.

## Issue

A discussion thread used to report a problem, suggest an idea, or plan work.

## Maintainer

A person or team responsible for reviewing and managing a project.

## Fork

A GitHub-hosted copy of a repository under another account.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
