# Roadmap: From Newbie to Contributor

You do not need to know everything before you begin. Use this roadmap as a sequence of small wins.

## 1. Create a safe foundation

Complete [profile setup](../01-getting-started/profile-setup.md), enable account security, and learn the interface.

## 2. Learn the basic vocabulary

Read the [glossary](glossary.md) and practice the fork, branch, commit, push, and pull request cycle.

## 3. Choose a friendly project

Look for recent activity, clear contribution instructions, and issues labelled `good first issue` or `help wanted`.

## 4. Make one useful change

Documentation, tests, translations, and small accessibility fixes are valid contributions.

## 5. Stay involved

Respond to review feedback, thank maintainers, join project discussions, and keep a short record of what you learned.

## Maintenance note
Check official sources before relying on time-sensitive rules, dates, badge criteria, or program details.
